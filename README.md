# AI Pathway GitHub Pages Starter

## What this is
A static, GitHub-Pages-friendly student home base for the AI pathway.

- Google Classroom remains the official place for assignments/submissions.
- This site is the student-facing map and lesson delivery layer.
- Lessons are stored as simple HTML pages and their content is controlled from `app.js`.

## Before publishing
Open `app.js` and change:
- `COURSE.startDate` to the actual first school day, e.g. `2026-08-18`
- `COURSE.classroomUrl` to your Google Classroom URL

Do not put student names, emails, grades, private student work, or other identifying information in this public repository.

## Current prototype
- Home page
- Automatic "Today's Lesson" framework
- Course Map → August → Day 1 / Day 2
- Day 1 and Day 2 lesson pages
- Previous / Course Map / Next navigation
- Time budgets
- Submit / Portfolio / Early Finish / Stuck sections

We will expand the course map and lesson data as the curriculum is built.
